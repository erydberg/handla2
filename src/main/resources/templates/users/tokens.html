API-nycklar

Ny nyckel skapad. Kopiera den nu, den visas inte igen:

  • skapad , senast använd

Så använder du nyckeln i Genvägar

  1. Diktera text (svenska)
  2. Hämta innehåll i URL: https://<din adress>/api/lists/<listans id>/articles, metod POST, rubrik Authorization = Bearer hk_…, JSON-brödtext text = Dikterad text. Listornas id får du med GET /api/lists.
  3. Om svaret har needsCategory = sant: Välj från lista bland categories, och skicka PUT /api/articles/<id>/category med JSON categoryId.
  4. Slå på Visa på Apple Watch och säg "Hej Siri, <genvägens namn>".
